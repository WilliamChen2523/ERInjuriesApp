# ERInjuriesApp

## Overview

ERInjuriesApp is a Shiny application for exploring emergency room injury data from the Mastering Shiny ER injuries case study.

## Features

* Summary tab for exploring injury variables
* Histograms for numeric variables
* Bar plots for categorical variables
* Summary statistics tables
* Narrative tab for viewing injury narratives by body part

## Installation

```r
source("R/run_app.R")
```

## Run the App

```r
run_app()
```

## Data Source

The app uses the injuries dataset from the openintro package.
